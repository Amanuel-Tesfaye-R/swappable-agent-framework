# Contributing to Swappable Agent Framework

We welcome contributions to specifications, architectural blueprints, and model provider adapters.

## Contribution Areas
- **Blueprints:** Refinements or new architectural patterns in the `blueprints/` directory.
- **Provider Adapters:** Implementations connecting new model backends (Mistral, DeepSeek, Local VLLM) in `examples/adapters/`.
- **Contracts & Specs:** Enhancements to prompt contract schemas.

## Guidelines
- Avoid provider lock-in: ensure all designs uphold the Power Source Principle.
- Provide clean TypeScript/JavaScript or schema examples.
